# Skaldoria CV

Skaldoria CV is a planned native desktop application for authoring professional CVs and résumés
in readable Markdown, previewing them as paginated documents, and exporting accessible,
ATS-friendly PDFs.

This directory currently defines the product and engineering contract. It is intentionally not a
Gradle module until implementation begins; an empty application module would violate the
repository's active-wiring rule.

See the [functional and non-functional requirements](./docs/REQUIREMENTS.md).
