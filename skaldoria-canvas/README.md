# Skaldoria Canvas

The standalone spatial canvas application. Canvas interaction, geometry, rendering, persistence,
and desktop interaction tests live in this module; reusable diagram primitives live in
`:skaldoria-shared-ui`.

```text
./gradlew :skaldoria-canvas:run
./gradlew :skaldoria-canvas:desktopTest
```

See [the application requirements](./docs/REQUIREMENTS.md).
