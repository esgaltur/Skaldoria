# Skaldoria Shared UI

Reusable Compose rendering infrastructure shared by Presentation, Writer, and Canvas, including
themes, Mermaid diagrams, mathematical formulas, geometry, and contrast utilities.

```bash
./gradlew :skaldoria-shared-ui:desktopTest
```

See [ADR-002: Diagram Geometry Architecture](./docs/adr/002-diagram-geometry-architecture.md).
