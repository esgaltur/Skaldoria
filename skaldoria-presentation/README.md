# Skaldoria Presentation Studio

The desktop presentation application. It owns the source editor, slide layouts, presenter and
projector windows, export pipeline, companion server, and presentation-specific state.

```bash
./gradlew :skaldoria-presentation:run
./gradlew :skaldoria-presentation:desktopTest
./gradlew :skaldoria-presentation:createDistributable
```

See the [presentation documentation](./docs/README.md) and
[functional specification](./docs/FUNCTIONAL_SPECIFICATION.md).
